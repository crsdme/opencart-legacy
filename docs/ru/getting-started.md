# Настройка магазина

Как запустить магазин: установка, настройки, модули, страницы, каталог, SEO и как тема собрана. Подробности движка — в `DOCUMENTATION.md`. Гайды по модулям: `faq.md`, `redirect_manager.md`, `import_export.md`, `backup.md`, `sms.md`.

Серые пунктирные блоки — слоты под скриншоты. Кладите PNG в `docs/images/getting-started/` с именем на боксе. После обновления страницы картинка подставится сама.

## Установка

Два способа дойти до `/install/`. Мастер после этого один. Выберите один вариант.

### Разработка (Docker)

Только локально. На живом хосте `docker-compose` не запускайте.

```bash
docker-compose up -d --build
```

Очистите `public_html/config.php` и `public_html/admin/config.php`, если там уже есть константы БД (прошлый инсталл). Затем откройте `http://localhost:8080/install`. phpMyAdmin: `http://localhost:8081`.

В образе уже есть GD (WebP), mysqli, zip, OpenSSL, rewrite. Шаг 2 мастера должен быть зелёным.

### Production (живой хост)

Apache + PHP 7.4 + MySQL 5.7 (или MariaDB с тем же SQL mode). Корень сайта — `public_html/`, не корень репозитория. Docker-стек на прод не выкладывайте.

1. Залейте `public_html/` (или `npm run git:deploy`, если используете subtree-ветку `deploy`). Скомпилированный `tailwind.css` едет с темой — на сервере `npm run dev` не нужен.
2. Скопируйте `config-dist.php` → `config.php` и `admin/config-dist.php` → `admin/config.php`. Оба файла должны быть доступны установщику на запись.
3. Если нет `.htaccess` — скопируйте `.htaccess.example` → `.htaccess`. Правила HTTPS и www→без www уже пропускают localhost; на реальном домене они работают.
4. Создайте пустую базу MySQL в панели хостинга. Запишите хост, имя, пользователя, пароль (хост часто `localhost`).
5. Расширения PHP: GD с WebP, mysqli, zip, OpenSSL, mbstring, curl, json. Папки `image/`, `image/cache/`, `image/catalog/`, `system/storage/` (cache, logs, download, modification, session, upload) должны быть доступны на запись.
6. Откройте `https://ваш-домен/install/`.

После мастера: удалите или закройте папку `install/`. В `.htaccess` раскомментируйте блок `/secureadmin`, чтобы спрятать `/admin`. Настройте SMTP и cron Auto Backup (`backup.md`) — не Docker.

![Старт установщика /install/](images/getting-started/01-install-start.png)

### Шаг 1 — Лицензия

Примите GPL. Настраивать нечего.

![Установка, шаг 1: лицензия](images/getting-started/02-install-license.png)

### Шаг 2 — Требования

Все строки зелёные. Если нет `config.php` — скопируйте из `config-dist.php` (то же для `admin/config.php`) и дайте право записи.

![Установка, шаг 2: PHP и папки](images/getting-started/03-install-requirements.png)

### Шаг 3 — База и админ

**Разработка (Docker):**

| Поле | Значение |
| --- | --- |
| Driver | MySQLi |
| Hostname | `mysql` или `mysql-db` (алиас compose) |
| Username | `opencart` |
| Password | `opencart` |
| Database | `opencart` |
| Port | `3306` |
| Prefix | `oc_` |

**Production:** те же поля, значения из панели хостинга. Hostname обычно `localhost`, не `mysql`. Свой префикс — только если база общая; иначе `oc_` нормально.

Дальше создайте пользователя админки.

![Установка, шаг 3: форма БД](images/getting-started/04-install-database.png)

**Стартовый контент** — главный выбор:

- **Empty store** (для настоящего магазина). Схема, локали, статусы, юридические страницы, *имена* макетов, системные дополнения. Без товаров, категорий, блога, баннеров и каруселей на главной. Страницы блога выключены.
- **Demo catalog** — демо-товары, блог, баннеры, модули главной (carousel / latest / special / blog_latest). Чтобы изучить админку, не как посев продакшена.

![Установка, шаг 3: Empty store или Demo catalog](images/getting-started/05-install-starter.png)

CLI: `php install/cli_install.php install … --sample_data 0` или `--sample_data 1`. Подробности: `DOCUMENTATION.md`.

После установки включены SEO URL, SeoPro и склейка CSS/JS (`config_minifier`). Языки магазина: украинский (основной), английский, русский. Часовой пояс `Europe/Kiev`.

### Шаг 4 — Готово

Откройте витрину и админку.

- **Разработка:** в Docker папку `/install/` можно оставить.
- **Production:** сразу удалите или закройте `install/`. Проверьте HTTPS, включённый minifier, выключенный показ ошибок.

![Установка, шаг 4: вход в админку](images/getting-started/06-install-done.png)

## Админка и настройки магазина

Админка: **Система → Настройки** (`route=setting/setting`). Сохраните форму хотя бы раз — так запишутся флаги страниц витрины.

![Дашборд после входа](images/getting-started/07-admin-dashboard.png)

### Общие

Тема **Default**. Макет по умолчанию **За замовчуванням**, если не хотите, чтобы любой неизвестный route брал главную.

### Магазин

Заполните **название, владельца, адрес, email, телефон**. Они идут в футер, контакты, письма и Organization JSON-LD. Логотип в шапке — спрайт темы, не это поле.

![Настройки → Магазин: имя и контакты](images/getting-started/08-settings-store.png)

### Локализация

Страна Украина, регион, пояс `Europe/Kiev`. Длина/вес — если считаете доставку по габаритам. Валюта UAH; автообновление только если включён движок курсов (ECB стоит, NBU есть, но не установлен).

Основной язык лучше оставить украинским, если магазин не English-first. Неосновные языки получают префикс URL (`/en/…`, `/ru/…`). См. `language-flow-session-config.md`.

![Настройки → Локализация: язык и валюта](images/getting-started/09-settings-local.png)

### Опции — каталог и оформление

| Настройка | Рекомендация |
| --- | --- |
| Лимит товаров на витрине | 16–24. Больше — тяжелее списки. |
| Длина описания в листинге | Короткая; карточке не нужен весь HTML. |
| Счётчик товаров в категориях | **Выкл** на большом каталоге (лишний COUNT). |
| Отзывы | Вкл, только если будете модерировать. Гостевые — выкл, иначе спам. |
| Гостевой заказ | **Вкл** для большинства магазинов. |
| Заказ при нулевом стоке | Выкл, если продаёте только то, что есть. |
| Попытки входа | Оставьте дефолт. |
| Cookie / GDPR | Укажите юридические страницы из инсталла. |

Поля чекаута **не здесь** — это модуль Checkout.

### Опции — страницы витрины

**Сторінки вітрини**. Выкл = route отдаёт 404, скрыт из sitemap, футера и меню. Это не 410. Если URL уже в индексе — сначала 301/410 в Redirect Manager.

| Семейство | Оставить вкл | Выключить |
| --- | --- | --- |
| Товары | Вы продаёте SKU. Вместе гасятся сравнение, поиск, акции, live search. | Сайт-визитка / только блог. |
| Категории | Обычный каталог. | Одна посадка + поиск (редко). |
| Производители | Бренды — отдельная навигация. | Брендов нет, или бренд только атрибут. |
| Информационные | Доставка, оферта, о нас. Попап оферты на чекауте живёт и при выкл. | Всё заменили одной формой контакта. |
| Контакт | Нужна форма. | Только телефон/мессенджеры. |
| HTML-карта | Лишний путь для обхода. XML остаётся. | Человеческая карта не нужна. |
| Блог | Будете писать. Empty-store уже выключает это. | Нет редакционного контента. |

Виджеты макета — не выключатель. Featured на главной всё равно ведёт на товары, если семейство товаров включено.

![Настройки → Опции: страницы витрины](images/getting-started/10-settings-pages.png)

### Опции — страницы кабинета

Вход, выход, пароль, дашборд, корзина, чекаут **нельзя** выключить.

Выключайте то, чем не пользуетесь: партнёрка, трекинг, сертификаты, регулярные платежи, бонусы, загрузки, возвраты, рассылка. Закладки — если выключили в теме. Регистрацию — только если чекаут чисто гостевой **и** аккаунты не нужны (вход по телефону всё равно создаёт аккаунт).

![Настройки → Опции: страницы кабинета](images/getting-started/11-settings-account-pages.png)

### Почта и SMS

На проде нужен SMTP (вкладка Почта). Docker может остаться на PHP `mail()`.

Вкладка SMS: в Docker шлюз **log**. Для входа по телефону на проде — TurboSMS или HTTP. Шаблон `{code}` живёт в настройках **темы Default**, не здесь. Подробности: `sms.md`.

### Сервер

| Настройка | Рекомендация |
| --- | --- |
| Обслуживание | Выкл на живом сайте. Вкл только на время замены каталога. |
| SEO URL | **Вкл**. Нужен Apache rewrite (в этом стеке есть). |
| Объединение CSS/JS (`config_minifier`) | **Вкл** на проде. Выкл, пока крутите CSS и мешает кэш бандла. |
| Сжатие | 0; gzip — на веб-сервере. |
| Показ ошибок | Выкл на проде. Лог: `system/storage/logs/error.log`. |
| Ключ шифрования | Оставьте значение инсталла. |

![Настройки → Сервер: SEO URL и minifier](images/getting-started/12-settings-server.png)

### SeoPro

SeoPro **вкл**. URL в нижнем регистре **вкл**. Слеш в конце: выберите один стиль и не меняйте после индексации. Путь категории в URL товара (`config_seo_url_include_path`): вкл для `/category/product`, выкл для короткого `/product`. Кэш ЧПУ **вкл** на проде; сбрасывайте после массовой правки keyword.

Постфикс (`.html`) — пустой, если не копируете старый сайт.

![Настройки → SeoPro](images/getting-started/13-settings-seopro.png)

### Микроразметка

JSON-LD и OpenGraph **вкл**. Twitter Cards по желанию. `sameAs` — по одному URL соцсети на строку. Facebook app id — только если нужен пиксель/верификация. Логотип Organization — пак favicon, не спрайт шапки.

![Настройки → Микроразметка](images/getting-started/14-settings-microdata.png)

### Тема Default

**Дополнения → Дополнения → Темы → Default**. Гостевые закладки — если нужны. **Вход в аккаунт**: email/пароль или SMS. Телефон прячет страницы email/пароля и создаёт аккаунт сам. Задайте **Текст SMS при входе** с `{code}` до включения.

![Тема Default: закладки и вход](images/getting-started/15-theme-default.png)

## Модули

**Дополнения → Дополнения**. Фильтр по типу (Модули, Доставка, Оплата, Каналы, Аналитика, Капча, Учёт заказа, Темы). Установить → **Изменить** → повесить на макет, если это блок витрины.

Админские инструменты (FAQ, Redirect Manager, Import/Export, Auto Backup, Checkout) на макет не ставятся.

![Список модулей](images/getting-started/16-extensions-modules.png)

### Блоки витрины (макеты)

**Дизайн → Макеты**. Позиции: `content_top`, `content_bottom`, `column_left`, `column_right`. Тема в основном в одну колонку — **content_top / content_bottom** на Главной, Категории, Товаре. На макетах кабинета уже стоит модуль Account справа.

![Дизайн → Макеты: главная с каруселью](images/getting-started/17-layouts.png)

| Модуль | Что делает | Когда |
| --- | --- | --- |
| Карусель | Баннеры desktop/mobile (Embla). Свои ширина/высота на брейкпоинте. | Герой главной. Сначала **Дизайн → Баннеры**. |
| Рекомендованные / Новинки / Акции / Хиты | Рейки товаров. Featured берёт товары и/или категории. | Низ главной и категорий. Лимит 8–16. |
| Блог: последние / избранные | Карточки статей. | Главная, только если блог включён. |
| HTML | Произвольный HTML. | Короткий промо-текст. Не новый тип страницы. |
| Фильтр | Фильтр по атрибутам в категории. | Только если атрибуты заполнены и будете их держать. В роадмапе модуль ещё «на пересмотр». |
| Аккаунт | Ссылки кабинета. | Уже на макетах аккаунта. |
| Витрина | Переключатель мультимагазина. | Не нужен без доп. магазинов. |

![Карусель: размеры desktop и mobile](images/getting-started/18-carousel.png)

![Рекомендованные: товары или категории](images/getting-started/19-featured.png)

Empty-store **не** создаёт экземпляры карусели/featured. Создайте их и положите на макет Главная.

### Чекаут, доставка, оплата, итоги

**Checkout** (Модули, также **Продажи → Оформление**): одностраничный чекаут. Вкладки: обязательные поля, минимум заказа, подписи доставки и оплаты, какие оплаты с какими доставками. Самовывоз может прятать адрес. Купон — в Учёте заказа.

![Модуль Checkout: поля и минимум](images/getting-started/20-checkout-module.png)

Доставка, которую стоит ставить: **Nova Poshta** (отделение / поштомат / курьер + виджет города), **Самовывоз**, **Фиксированная**. Weight/item/free — только если так считаете тариф.

Оплата: **Накладной платёж**, **Банковский перевод**, **LiqPay**. Cheque/free — для тестов.

Итоги, которые должны быть включены: Подытог, Доставка, Итого. Купон — если есть промокоды. Налог — только если настроены классы.

### SEO и эксплуатация

| Модуль | Роль |
| --- | --- |
| FAQ | Вопросы на товаре / категории / производителе + FAQPage JSON-LD. Установить и выдать права. `faq.md`. |
| Redirect Manager | 301 и 410 на Apache/Nginx/Cloudflare/PHP. `redirect_manager.md`. |
| Import / Export | CSV/JSON каталога (не SQL-дамп). `import_export.md`. |
| Auto Backup | Cron на проде: БД + `image/catalog`. Не для Docker. `backup.md`. |
| XML Sitemap | Канал, установлен и включён. Человеческий URL `/sitemap.xml`. |
| Google Analytics | **Не вставляет gtag.** Счётчик вставляете сами. Модуль шлёт события GA4 ecommerce в `gtag` или `dataLayer`. |
| Google Shopping / Google Base | Опциональный фид. По умолчанию не установлен. |
| Капча | Basic или Google. На контакт/регистрацию, если есть спам. |

## Страницы

Каждое семейство — макет (Дизайн → Макеты) плюс route. Не используете — выключите в настройках. Вкладка **Дизайн** у сущности может подменить макет (отдельный лендинг товара).

### Главная (`common/home`)

Макет **Головна**. Карусель + одна-две рейки товаров. Не сваливайте все модули на главную. Над сгибом — легко (один герой, не три слайдера).

![Главная витрины](images/getting-started/27-home.png)

### Категории (`product/category`)

Дерево в **Каталог → Категории**. Keyword на каждый язык. Путь родитель/потомок попадает в URL, если include-path включён. FAQ листинга — под сеткой товаров. Фильтры — только если модуль Filter на этом макете.

Не заводите пустые категории «на потом» — их всё равно проиндексируют.

![Страница категории](images/getting-started/28-category.png)

### Товары (`product/product`)

Карточка, галерея, опции, характеристики, FAQ, отзывы. Сравнение и поиск завязаны на флаг семейства товаров. Страница акций (`product/special`) — тот же флаг.

![Страница товара](images/getting-started/29-product.png)

### Производители (`product/manufacturer`)

Список + страница бренда. Включайте, только если бренд — реальный путь навигации. Иначе производитель только на карточке товара, без отдельных URL.

![Страница производителя](images/getting-started/30-manufacturer.png)

### Блог (`blog/*`)

Лента, категория, статья, автор. Пустой инсталл оставляет `config_pages_blog` выкл — включите в Опциях, когда готовы. Меню в шапке следует флагу. Макеты: Блог / Категорії Блогу / Статті Блогу.

![Лента блога](images/getting-started/31-blog.png)

### Кабинет (`account/*`)

Дашборд, заказы, адреса и флаги из Опций. Вход по телефону меняет вид логина/регистрации. Корзина и чекаут остаются доступны.

![Кабинет](images/getting-started/32-account.png)

### Оформление (`checkout/checkout`)

Одна страница. Старый аккордеон — `checkout_old`, на него не ссылаться. Поля — модуль Checkout, методы — Доставка/Оплата. Success шлёт `purchase`, если события Analytics включены.

![Одностраничный чекаут](images/getting-started/33-checkout.png)

### Информационные, контакт, HTML-карта

CMS: **Каталог → Статьи** (доставка, оферта, политика). Контакт — `information/contact`. HTML-карта — `information/sitemap`, её можно выключить, XML останется.

![Статья или контакт](images/getting-started/34-information-contact.png)

### 404 и 410

404 (`error/not_found`) — «семейство выключено или keyword неизвестен». 410 (`error/gone`) — «URL убрали нарочно». У обоих есть макеты, можно поставить HTML-модуль. Снимаете проиндексированный URL → Redirect Manager 410, не тихий 404.

![Страница 410 Gone](images/getting-started/35-error-410.png)

## Наполнение каталога

Сначала таксономия, потом товары. Import/Export быстрее кликов, когда есть таблица. Сначала preview, потом запись.

### Категории

Имя, родитель, картинка (необязательно), магазины, сорт, статус, уникальный keyword на язык. Описание: короткий уникальный текст, не список дочерних имён. `meta_h1` — только если H1 должен отличаться от названия. `noindex` для дублей и фасетов.

![Форма категории](images/getting-started/40-category-form.png)

### Производители

То же: имя, картинка, keyword. Не заводите сущность, если страницы брендов выключены.

### Характеристики

**Каталог → Характеристики**: группы (Экран, Питание), затем атрибуты (Диагональ, Ёмкость). Значения — у товара. Это таблица на карточке, сравнение и модуль Filter. Имена стабильные; не плодите атрибут на каждый SKU.

![Группы характеристик](images/getting-started/42-attribute-groups.png)

### Форма товара

Важные вкладки:

| Вкладка | Что заполнять |
| --- | --- |
| Общие | Имя, описание (живой текст), `meta_title` / `meta_description` / `meta_h1` только если шаблонов в `catalog/language/*/seo/meta.php` мало. Вкладка FAQ появляется после установки FAQ. |
| Данные | Уникальные model/SKU, цена, количество, статус, дата поступления, флаг доставки, вес если доставка по весу. |
| Связи | Категории (одна основная + доп.), производитель, связанные (умеренно), магазины. |
| Характеристики | Значения из групп выше. Одна формулировка на все SKU. |
| Опции | Размер/цвет, только если меняют строку корзины. «Материал» — в характеристики. |
| Изображения | Главное + доп. Импортёр качает `http(s)` в `image/catalog/import/`. |
| SEO | Keyword на язык. Уникальный. Без пробелов. |
| Дизайн | Свой макет только для редких лендингов. |
| Скидки / Акции / Бонусы / Подписки | Пропустите, если программ нет. |

## SEO

Скорость и гигиена обхода уже в ядре. Не ставьте сверху случайный «SEO-пак».

### Бандлер (minifier)

`Custom\Minifier` склеивает подряд идущие локальные CSS/JS из контроллеров. CDN остаётся отдельно. Бандлы: `image/cache/minifier/<store_id>/`. Тумблер: Настройки → Сервер → **Об’єднання CSS/JS**. HTML не минифицируется. Стили страницы — из контроллера, не из Twig. UI → `stylesheet/ui.css`; витрина → `catalog.css`; товар → `product.css`; чекаут → `checkout.css` (грузится контроллером, не в Tailwind-бандле). Не кладите CSS компонентов в `stylesheet.css` или `docs.css`.

### WebP

`catalog/model/tool/image.php` `resize()` пишет JPEG/PNG-кэш и WebP, если GD умеет и в `Accept` есть `image/webp`. Шаблоны по-прежнему зовут `resize()`. Оригиналы в `image/catalog/`.

### Микроразметка

`common/microdata` → OpenGraph в `<head>`, JSON-LD перед `</body>`: Organization, WebSite, WebPage, BreadcrumbList, Product, ItemList, FAQPage. FAQ только JSON-LD — не вешайте FAQ-микродату на аккордеон. Вкладка настроек Microdata.

### Google Analytics ecommerce

gtag или GTM вставляете сами (HTML-модуль или в крайнем случае `head.twig`). Затем **Дополнения → Аналитика → Google Analytics** и нужные события: `view_item`, `view_item_list`, `view_search_results`, `view_cart`, `add_to_cart`, `remove_from_cart`, `begin_checkout`, `add_shipping_info`, `add_payment_info`, `purchase`.

### Redirect Manager

301 если URL переехал. 410 если его больше нет. Карту старого сайта импортируйте **до** запуска. В Docker — Apache RewriteMap; есть PHP-fallback. `redirect_manager.md`.

![Правила Redirect Manager](images/getting-started/44-redirect-rules.png)

### Мультиязык и роутер

Старт: язык → снять префикс → `Custom\Router` → Redirect Manager → флаги страниц. Keyword в `seo_url`. У основного языка префикса нет. Hreflang собирается сам. Второй роутер не нужен.

### Meta-data

Шаблоны в `catalog/language/{ua,en,ru}/seo/meta.php` (`{shop}`, `{name}`, …). Поля сущности побеждают, если заполнены. H1 из того же билдера. Суффикс пагинации только в `<title>`. Глобального title в настройках магазина нет.

![Мета товара и шаблоны](images/getting-started/43-seo-meta.png)

### FAQ

Общие вопросы на тип + на страницу. Плейсхолдеры `{name}` `{price}` `{category}` `{month}` `{year}`. «Только первая страница листинга» — чтобы FAQ не повторялся на `?page=2`. `faq.md`.

![Аккордеон FAQ на товаре](images/getting-started/46-faq-storefront.png)

### 410

Темированная `error/gone`, HTTP 410, `noindex,follow`. Route ставит только Redirect Manager (или веб-сервер). Флаги страниц 410 не отдают.

### Sitemap

XML: `/sitemap.xml` (и `/en/sitemap.xml`). Ветки: main, categories, products, information, manufacturers, blog-*. Выключенные семейства пропускаются. Кэш 24ч в `system/storage/cache/sitemap_*`. В `robots.txt` укажите `Sitemap:` на живой домен. HTML-карта необязательна.

![Индекс sitemap.xml](images/getting-started/45-sitemap-xml.png)

## Разработка

Работайте в этом репозитории, не на проде. Тот же Docker, та же тема, тот же стиль кода.

### Устройство проекта

| Путь | Роль |
| --- | --- |
| `public_html/catalog/controller` | Роуты витрины. |
| `public_html/catalog/model` | Чтение БД. |
| `public_html/catalog/view/theme/default` | Twig, CSS, JS, `components/`. |
| `public_html/catalog/language/{ua,en,ru}` | Строки витрины + `seo/meta.php`. |
| `public_html/system/library/custom` | Роутер, флаги страниц, minifier, docs, мультиязык. |
| `public_html/admin` | MVC админки. |
| `docs/en`, `docs/ru` | Этот сайт (`/index.php?route=docs`). Скриншоты в `docs/images/`. |
| `docker/` | PHP 7.4 Apache, php.ini, vhost. |

Оболочка: `common/layout.twig` рисует head → header → контент route → footer → microdata. Колонки — из **Дизайн → Макеты**, не из Twig route.

![Форма макета: позиции](images/getting-started/48-layout-positions.png)

### Как повесить функционал на страницу

Берите самый маленький крючок:

1. **Готовый модуль + макет.** Карусель, featured, HTML, блог. Админка → Дизайн → Макеты → тип страницы → `content_top` / `content_bottom`. Так делают маркетинговые блоки.
2. **Макет сущности.** Вкладка **Дизайн** у товара/категории → другой макет, если одной посадке нужен другой набор.
3. **Флаг семейства.** Настройки → Опции. Весь route исчезает. Не для прятания одного виджета.
4. **Twig include.** UI: `{% include 'default/components/….twig' %}`. Галерея: `/index.php?route=docs/components`. Новые куски — в `components/` плюс свой CSS/JS и превью в галерее.
5. **Ассеты из контроллера.** CSS/JS страницы: `$this->document->addStyle(...)` / `addScript(..., 'footer')`. Глобальный UI → `stylesheet/ui.css`; витрина → `catalog.css`; товар → `product.css`; чекаут → `checkout.css`. Не кладите CSS компонентов в `stylesheet.css` или `docs.css`.
6. **События.** Вкладки FAQ — events, не OCMOD. Events, когда новая вкладка нужна на каждой форме товара.
7. **Своя библиотека.** Общий PHP в `system/library/custom` (или `system/library/sms` для шлюзов). Контроллеры тонкие.

**Не** форкайте вторую тему. **Не** правьте прод. **Не** копируйте 200 строк в HTML-модуль, если уже есть компонент.

![Галерея компонентов](images/getting-started/49-components-gallery.png)

### Локальный цикл

```bash
docker-compose up -d
npm run dev          # Tailwind → tailwind.css
npm run prettier     # Twig / CSS / JS / catalog PHP
```

`dev_dump($var)` печатает `<pre>`. Лог: `public_html/system/storage/logs/error.log`. После `git pull` пересоздайте PHP-контейнер, если `docs/` не примонтирован.

### Новый модуль витрины

1. Контроллер/модель/Twig в `extension/module/{code}`.
2. Установить в Дополнениях, включить статус.
3. Если это блок: **Добавить** экземпляр (имя, настройки) и повесить его на макет. Статуса расширения мало — нужен экземпляр на макете.
4. Если это только настройки (Checkout, FAQ) — макет не нужен, каталог читает config.

Тот же паттерн, что у Featured: статус + экземпляр + строка макета.

## Чеклист запуска

1. Empty-store (или вычищенное демо).
2. Настройки: имя магазина, языки, SEO URL, minifier, микроразметка, ненужные страницы выкл.
3. Тема: способ входа, текст SMS если телефон.
4. Чекаут + одна доставка + одна оплата + нужные итоги.
5. Категории → характеристики → товары (или Import/Export).
6. Макет главной: карусель + featured, только если есть баннеры и товары.
7. FAQ + события Analytics + Redirect Manager для старого сайта.
8. `robots.txt` с sitemap, пак favicon, юридические статьи.
9. Cron Auto Backup на живом хосте, не в Docker.
